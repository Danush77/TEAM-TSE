ABOUT

Trainee Software Engineer, spelled out.

TSE stands for Trainee Software Engineer. It's the name for anyone on the team who's early in their engineering path and learning by building real, reviewed work rather than isolated exercises.

OUR PURPOSE

Skills stick when the work is real.

Tutorials teach syntax. They rarely teach what it feels like to open a pull request, get asked to change something, and push a fix. This team learns software engineering by practicing the whole loop on a project that other people actually use and review — starting with this website.

HOW WE LEARN

The same loop, every time.

learn

Pick a concept

practice

Try it in isolation

build

Apply it to the site

share

Open a pull request

review

Get real feedback

improve

Revise and merge

WHAT WE FOCUS ON

The roadmap flexes. The habits don't.

The specific technologies a trainee is learning will change over time — that's expected. What stays constant is how the team works.

Programming fundamentals

Logic, data, and clean structure before frameworks.

Web development

HTML, CSS, and JavaScript, learned on this codebase.

Git & GitHub

Branches, PRs, reviews, and resolving real conflicts.

Problem solving

Breaking a vague ask into a shippable change.

Projects

Small, finished things over large, abandoned ones.

Continuous learning

Daily progress, tracked in the open on your own profile.
